# Changelog

## 0.1.0 — 2026-10-16

- First standalone release of the Arc CDP search extension.
- Google search and Markdown page reading through an existing browser session.
- Optional local CDP discovery bridge for pi-computer-use.
- Installable Pi package, English and Traditional Chinese documentation, MIT license, and CI.
- Clear navigation timers after loading and cleanup so finished tool calls do not keep the process alive.
- Report invalid tool arguments as tool failures, with types compatible with Pi 1.3.
